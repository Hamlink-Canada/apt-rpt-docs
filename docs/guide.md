# Documentation guide

This site is the operator and maintainer guide for Apt-RPT network systems.
Start at [the site index](index.md), then use the Portal, Registration,
Deployment, and Reference sections to find system and project guidance. See
[current decisions](decisions.md) for cross-project choices and [the glossary](glossary.md)
for shared terms.

Each source repository keeps its own standalone documentation. This site describes
how the repositories fit together and provides the cross-project operating view.
