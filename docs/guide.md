# Documentation guide

This directory is the operator and maintainer guide for the repeater registration
projects. Start at [the site index](index.md), then use the project sections for
deployment, configuration, operations, and development. See [current decisions](decisions.md)
for cross-project choices and [the glossary](glossary.md) for shared terms.

Each source repository keeps its own standalone documentation. This site describes
how the repositories fit together and provides the cross-project operating view.
