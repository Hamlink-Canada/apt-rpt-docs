# Portal frontend configuration

Production runtime settings are generated by the container entrypoint and
served at `/config.json`. The browser fetches this file before initializing
Vue or OIDC. Set values as environment variables or in the optional JSON file
(default `/etc/portal/config.json`). Explicitly provided environment variables
override matching file values. `PORTAL_CONFIG_FILE` selects another file path.

## Production runtime settings

| Environment variable | JSON field | Default | Description |
| --- | --- | --- | --- |
| `PORTAL_CONFIG_FILE` | — | `/etc/portal/config.json` | Optional JSON config file path mounted in the container. A missing file is allowed. |
| `PORTAL_MANAGEMENT_DISPLAY_NAME` | `managementDisplayName` | `Portal` | Name shown in the management interface. |
| `PORTAL_OIDC_AUTHORITY` | `oidcAuthority` | empty; required | OIDC authority used for discovery and sign-in. |
| `PORTAL_OIDC_CLIENT_ID` | `oidcClientId` | empty; required | Public browser client identifier. |
| `PORTAL_ACCOUNT_MANAGEMENT_URL` | `accountManagementUrl` | empty | Optional account-management URL; when empty, the app derives the Keycloak account console URL from the OIDC authority. |
| `PORTAL_API_BASE_URL` | `apiBaseUrl` | `/api` | Backend API base path or URL used by the browser. |

The JSON file must be an object containing only the five listed fields. Every
value must be a string. `managementDisplayName`, OIDC authority, OIDC client
ID, and API base URL must be non-empty after merging. An invalid file or
missing required value causes the container to exit. These values are public
browser configuration; do not include secrets.

Example JSON:

```json
{
  "managementDisplayName": "Portal",
  "oidcAuthority": "https://identity.example.invalid/realms/example",
  "oidcClientId": "portal-management",
  "accountManagementUrl": "",
  "apiBaseUrl": "/api"
}
```

## Vite development settings

Vite reads local values at build or development-server startup. The `.env.example`
file lists these settings; it is not loaded as production container
configuration.

| Variable | Default | Description |
| --- | --- | --- |
| `VITE_MANAGEMENT_DISPLAY_NAME` | `Portal` | Development display name. |
| `VITE_OIDC_AUTHORITY` | empty | OIDC authority for normal local sign-in. Not required while the local mock is enabled. |
| `VITE_OIDC_CLIENT_ID` | empty | Public OIDC client ID for normal local sign-in. Not required while the local mock is enabled. |
| `VITE_ACCOUNT_MANAGEMENT_URL` | empty | Optional account URL; empty uses the Keycloak realm account console derivation. |
| `VITE_API_BASE_URL` | `/api` | API base path for frontend requests. |
| `VITE_API_PROXY_TARGET` | `http://127.0.0.1:5000` | Vite development-server proxy target for `/api`. |
| `VITE_PORTAL_DEV_MODE` | `false` | Enables the frontend's development-only mock sign-in and preview UI when running Vite. |
| `VITE_PORTAL_BACKEND_PREVIEW` | `false` | Uses the backend mock identity endpoints when frontend development mode is enabled. |

The local mock is gated by Vite's development flag and is excluded from
production behavior. The frontend-only mock does not call the backend. Use
backend preview mode only when the backend is running with its guarded local
preview settings.
